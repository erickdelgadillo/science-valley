A pixel-art science simulation game where experiments, discovery, and research replace farming.

## Overview

Science Valley is an experimental 2D game built with **Godot**.

The project takes inspiration from life-simulation and farming games, but replaces traditional farming mechanics with scientific activities such as:

- laboratory work
- experiments
- sample collection
- research
- scientific discovery
- progression through new techniques and equipment

The long-term goal is to create a relaxing pixel-art game centered around the everyday life of a scientist.

## Controls

Movement:

```text
W / ↑    Move up
S / ↓    Move down
A / ←    Move left
D / →    Move right
```

Requirements
Godot 4.7
Running the project

Clone the repository:
```bash

git clone https://github.com/erickdelgadillo/science-valley.git
cd science-valley

Open the project in Godot:

godot --editor project.godot
```

Or import project.godot directly from the Godot Project Manager.

Development status

Science Valley is currently an experimental personal project and is under active development.
